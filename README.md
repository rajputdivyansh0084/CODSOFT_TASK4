#  Spam SMS Detection using Machine Learning

##  Project Overview

This project focuses on building a Machine Learning model that classifies SMS messages as Spam or Legitimate (Ham).

Using Natural Language Processing (NLP) techniques and Machine Learning classification algorithms, the model analyzes SMS text and identifies unwanted or suspicious messages.

This project is completed as **Task 4** of the CODSOFT Machine Learning Internship.

##  Objectives

- Classify SMS messages as Spam or Legitimate (Ham).
- Apply Natural Language Processing techniques to textual data.
- Perform text preprocessing and feature extraction.
- Convert text into numerical features using TF-IDF.
- Train and evaluate Machine Learning classification models.
